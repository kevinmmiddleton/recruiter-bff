# Interview Guide: Template

Saved as `job-search/interviews/<company>/guide.md`. One guide per company; each round adds a section, and earlier rounds are never overwritten.

The top of the guide is what the user reads in the five minutes before a call: the verdict, the next round, then the four blocks. Everything else sits below, for the night before.

---

```markdown
# [Company]: [Role]

_Updated YYYY-MM-DD · from the posting saved [date] · [live on the company's site / couldn't confirm]_

**Next round:** [Weekday Month Day, time, time zone] · [round type] with [name, title]
- **It tests:** [what this round is really for]
- **It doesn't test:** [what not to over-prepare for this round]

---
```

## Notes

- **The top must fit on one screen.** If the verdict, next round, and four blocks run past that, cut words, not blocks.
- **Real dates with weekdays.** "Thu Oct 8, 2:00pm ET," never "Thursday" alone.
- **Mark what you couldn't verify.** A fact without a source goes under "Couldn't verify," never in the snapshot.
