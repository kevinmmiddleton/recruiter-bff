# The Skeptical Review Pass

Read every draft the way a tired, skeptical hiring manager would, then fix what fails. Run it on resume bullets, summaries, LinkedIn text, cover notes, and application answers before handing them over.

## What to flag

| Flag | What it looks like | Fix |
|---|---|---|
| **Flattery** | "Your innovative, world-class team" | Cut it. Name one specific thing about them instead, or nothing. |
| **Groveling** | "I would be truly honored," "I hope you'll consider" | State interest plainly once: "I'd like to talk about this role." |
| **Adjectives as evidence** | "Highly strategic, results-driven leader" | Replace with the proof: what happened, with a number. |
| **Buzzwords** | "Leverage synergies," "drive cross-functional alignment," "passionate about" | Say what was actually done, in plain words. |
| **Could go to any company** | "I'm excited by your mission and growth" | The swap test: if another name fits, add a fact only research turns up. |
| **Throat-clearing opener** | "I'm writing to express my interest in..." "In today's fast-moving market..." | Delete the first sentence. Start on the concrete: a result, a company, a build. |
| **Slogan closer** | "Let's build the future together!" | End on the last real point, or a plain line about next steps. |
| **Three examples where two do** | "Strategy, execution, and leadership" | Use as many as the point needs. Two, or one strong one, usually wins. |
| **Inflated scope** | "Led" for "contributed to," "owned" for "supported" | Use the verb the user could defend in a follow-up question. |
| **Unsourced claim** | A number or tool that isn't in the resume or profile | Cut it, or ask the user and add a placeholder. |
| **Team result as solo** | "I grew revenue 40%" when a team did | "Our team grew revenue 40%; I led [the user's part]." |
| **Self-deprecation** | "Just a small project," "I only..." | Remove it. State the work plainly. |

## Voice defaults

Unless the user's own edits say otherwise:

- Delete the opener; start on the substance.
- No slogan closer in form fields.
- Don't default to three examples.
- Fewer words. If a sentence works without a phrase, cut the phrase.
- Keep the warmth. Plain and direct isn't cold; one human line is fine.
- No em dashes; use commas, periods, or colons.

## How to show it

Hand back the revised draft first, then a short list:

> **What I changed:** cut the opener; swapped "results-driven" for the conversion number; added the fact about their new pricing page so it passes the swap test.

Keep the list to the changes that teach something. The user should get better at this, not just get a better draft.
