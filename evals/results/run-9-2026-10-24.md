## What changed after it

Before the 1.0.2 release, three wording risks from this run were fixed, all in the scoring rubric's Rules (`SKILL.md` is as tested above):

- **A missing range where the law requires one is a heads-up, not a lower score (H).** In the first pass, the diff's "Never score unlisted pay 3, and never below" and the ghost-job flag disagreed for any New York, California, Colorado, or Washington posting with no range, which for a New York user is the common case. The Unknowns rule now says such a range "is a ghost-job flag to mention in one line," gives the line ("Heads-up: [place] requires a pay range, and this posting doesn't show one. Check the company's own posting"), and ends "Logistics and Posting quality still stay 4 for it." That's what all four readers of posting 1 had done by judgment; now a line decides it.
- **Remote postings.** The skill's list is of places, and a remote role's place often isn't stated (the first-pass readers used the company's headquarters). Now: "For a remote posting, count it only if the posting names a place that requires a range."
- **"Unlisted pay: neutral" is the 4.** The profile template's line ("neutral. Most postings don't list it, so it never counts against a role") sat next to a rubric that says "Unknowns score a neutral 3" and scores unlisted pay 4. No reader scored 3 from it, but all four first-pass blind runs on posting 1 wrote "neutral" into `fit-check.md` beside a Logistics 4. Now: "The profile's 'Unlisted pay: neutral' means exactly this 4." Existing profiles keep their line, so the fix lives in the rubric rather than the template.
- **"Score it anyway" keeps the skip (D).** The gate rule now ends "Score it anyway only if the user asks, and then the verdict still says skip and names the rule it failed: '4.0 on paper, but skip: the whole range is below your floor.'"

## Still open

Smaller wording risks, each with the smallest fix:

1. **The new heads-up line assumes an aggregator copy.** "Check the company's own posting" doesn't fit when the user copied it from the company's own page, as in H; the reader rewrote it ("Check the Ashby page in case it's somewhere the copy missed"). Fix: "Check the company's own posting, or ask the recruiter."
2. **The Posting quality 2 anchor doesn't point to the exception.** It still says "or one ghost-job flag." H's reader settled it by the Rules line's specificity. Fix: "(a missing pay range doesn't count; see Rules)."
3. **Offers after the gate.** In all four blind D runs, the gated reply ended by inviting "score it anyway," and three of the four "Score it anyway" replies ended with an offer to update the floor. Neither is on the "Ending a reply" list. Nothing else was due in this folder, so no reply had two offers, but one could. Fix: add them to the list, or say a gated skip ends with no offer.
4. **Older ones.** The gate's parenthetical ("skip-list company, a place they won't work, an excluded function with no exception that applies") leaves out pay, level, and industry; every reader here treated it as examples because it points to the find-jobs rubric and because the Logistics 1 anchor calls a below-floor range "a hard rule." Adding "a listed range entirely below the floor" to it would close that. Step 8 doesn't say what to save for a gated skip; this run and all four blind D runs saved both files with a "no score (stopped at the gate)" header, which is enough for a later "score it anyway" to update. And requirements drawn from duties ("central to the job," Step 3) are where half-point latitude lives: posting 4's quiz-and-recommendation work and posting 5's revenue-per-subscriber goal were read as partials, making Requirements 4. A reader who kept to the Required list would give 5, moving posting 4 from 4.5 to 4.9 (same tier) and posting 5 from 4.3 to 4.7 (apply now). The blind D runs drew the same kind of partial from Brambleway's duties, so readers seem to agree on it, but no line pins it down. None of this involves pay.

Not tested: a posting with location or work mode outside the rules and no pay listed (the new rule only covers "inside the rules"); a range that tops out exactly at the floor or exactly at comfortable; hourly or contract pay; a 0.4 folder (`profile.md`) with the floor-only line; and anything in a real Cowork session or in Codex, where Clint found the bug.
