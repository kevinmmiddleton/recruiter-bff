## Still open

Wording risks seen in this run, most important first. None failed a check.

1. **A placeholder-name role comes back every scan.** The new `same()` rule matches "Stealth Startup" on the link only, and pasted LinkedIn cards have no links. The scheduled digest showed Oct 10's Stealth Startup lifecycle role as new and recorded a second row; the case 3 reader flagged it ("this Stealth Startup role will come back as 'new' on every pasted scan"); a case 2 reader told the user. The digest reader handled it well on its own ("Your Oct 10 scan also showed a Stealth Startup lifecycle role. With no company name or link, I can't tell whether this is the same job."). Smallest fix, in `find-jobs` Step 4b: "A placeholder-name role with no link is never held back; if the history has one with the same title, say it may be the one shown on that date."
2. **"I applied to X" with one row at X.** Two of four case 1 readers asked which Fernhill role, citing "Never guess which application an update or a rejection belongs to. Ask." and matching rule 3; two named the row and invited a correction. One noted the update snippet with `role = None` updates that row without asking. Smallest fix, under "I applied to X": "If X has one open row, log that one and name it in the reply; ask only when there are two or more."
3. **Where the backup goes.** All four readers noted the line names the backup file but not its folder; all four put it in `job-search/`. Smallest fix: "`job-search/job-tracker-backup-YYYY-MM-DD.csv`".
4. **Asking for a missing pay number in the guide reply.** c5-2 asked "your profile has no ideal base number yet. What is it?" before its practice-run offer, from `answers-and-scripts.md`: "Know all three before any call; if they aren't set, ask before the round." c5-1 didn't ask. Both replies had one offer, but c5-2's asked two things. Smallest fix: "ask before the round, as a line in the guide's prep checklist."
5. **The tag example in Step 4b.** "Shown Oct 24, still open" read like today's date to two readers, since a returning role is 31 to 60 days old. Smallest fix: "Shown Sep 19, still open" (as `scan-history.md` does with "Sep 1").
6. **The resume in the notes.** Two readers wrote "applied with the primary resume" though the user didn't say; two wrote "applied." The profile says "No alternate." Low. Smallest fix: "If the profile has no alternate, note the primary."

Not tested: a real Cowork session; a browser; Windows; a stray comma whose place is ambiguous (in `notes`); the same repair path in `contacts.csv`; a user who says no to the fix or fixes it by hand; a scheduled digest whose user can reply.
