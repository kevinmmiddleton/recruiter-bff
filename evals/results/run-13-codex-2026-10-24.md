# Run 13: real Codex, Mac (Oct 24, 2026)

The first runs in real Codex instead of an agent playing it. Every name is fictional (Sam Okafor, the usual persona).

**Setup.** Codex CLI 0.164.0 on a Mac, signed in with a free ChatGPT account, so every turn ran on GPT-6 Luna (the free plan's model; GPT-6.1 Sol needs Plus). Plugin 1.1.0 from the `v1.1-launch` branch, installed with `codex plugin marketplace add` (a local copy) and `codex plugin add recruiter-bff@recruiter-bff`, the same two commands the README gives. Each turn was `codex exec` in an empty folder with the workspace-write sandbox (network off), as a new session or a resumed one. Expectations were written and hashed before the first turn (`f1624c30...`). Then the ChatGPT desktop app, for the one thing the CLI can't do: scheduled tasks.

## What real Codex showed about Codex itself

- **Install and discovery work.** Both commands succeed; the eight skills land in Codex's plugin cache and show up as `recruiter-bff:find-jobs` and so on. Codex picked the right skill from plain words every time.
- **The CLI has no browser and no scheduler.** Asked to list its tools, Codex CLI named a shell, a question tool (`request_user_input`), and web search, and answered no to scheduling and to driving a browser.
- **The ChatGPT desktop app does schedule.** Codex there has `automation_update` (from the app's own `codex_app` tool server). The app's instructions tell it to look for that tool for any reminder.
- **A read-only sandbox is handled well.** A resumed turn ran read-only by mistake (the test script's fault). The setup skill saved nothing, said exactly why ("the workspace switched to read-only ... No files were changed"), kept the answers, and saved everything on the next turn once the folder was writable.

## Fixes (commit `43a952a`)

- The rubric's example is neutral, and rule 10 now says an unknown company never keeps a role that fails an earlier rule.
- find-jobs opens with "Every scan, in order": read the rubric and scan history, gather, tracker check, the `seen_before` snippet, classify by the rules in order, present, the `record` snippet, one offer.
- Web search is not a substitute for the company job site searches or the watchlist feed. Without a browser or network, those sources say "skipped (no browser)" or "not available" with the reason, never checked or empty.
- The scan layout is followed as shown (ranges with "to," no dashes).
- The tracker, contacts, and scan history run their snippets as written, never hand-written CSV code.

## Fixes after the Sol runs (commit `dbedcb1`)

- Fit check tie-breakers: a skill only listed is a partial for a requirement that asks for strength or depth; a company whose subject matches the user's background scores 4.
- Scan layout: "Company: Role" with a colon, no em dashes in the reply.
- Codex CLI reminders: with days and a time named, make the calendar reminder, then offer the check-in; always say Codex in the ChatGPT app can schedule.
